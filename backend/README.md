# ClearPolicy backend

The Flask API accepts privacy-policy text and returns a reader-focused summary
generated by GPT through the OpenAI Responses API.

## Run locally

From the project root, set the key and start Flask:

```powershell
$env:OPENAI_API_KEY = "your-api-key"
.\.venv\Scripts\python.exe backend\app.py
```

The default model ID is `gpt-6-luna`; set `OPENAI_MODEL` before startup to
select another compatible model. The health endpoint reports the configured
model at `/healthz`.

## Analysis endpoint

`POST /api/v1/analyses` accepts the request in
`../contracts/analysis-request.schema.json` and returns the response in
`../contracts/analysis-response.schema.json`. Send a JSON object containing
the complete policy in its `text` field.

The response includes a plain-language overview, useful policy details with
source quotations, wording to review, and questions for the reader. The
backend verifies that each returned quote appears in the submitted text.

## Privacy and operations

The request sets `store=false` when calling OpenAI. The backend does not
persist policy text or write it to application logs. Keep `OPENAI_API_KEY`
server-side and set `ANALYSIS_API_TOKEN` in non-local deployments. Request
size and in-memory rate limits are configurable; see `OPERATIONS.md`.

The output is an AI-generated reading aid. It can omit or misinterpret details
and is not legal advice or a compliance determination.
