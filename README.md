# Privacy Policy Analyzer

A React rough-draft interface for the COMP 496 Privacy Policy Analyzer proposal.

## Run locally

```powershell
pnpm install
pnpm dev
```

The prototype supports pasting policy text or uploading `.txt` files and produces browser-only, rule-based draft findings for data collection, sharing, legal terms, user controls, and readability. It is educational UI only and not legal advice.
